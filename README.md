# TIWSHOP (แอพมือถือ) v1.1.0

แอพ Android สำหรับเกจ TIWSHOP SMART GAUGE (ต่อทางบลูทูธ) ปรับจาก FTP-CONNECT 1.0.0

## สิ่งที่เปลี่ยน
- ชื่อแอพ **TIWSHOP**, ไอคอน / หน้าเปิดแอพ / โลโก้หัวจอ = โลโก้ TIWSHOP SMART GAUGE, พื้นหลังรังผึ้งเขียวทุกหน้า
- สีธีมเริ่มต้น = เขียวนีออน (ถ้าเคยเลือกสีไว้ในแอพเดิม จะใช้สีเดิม)
- **ลื่นขึ้น ไม่ค้าง**
  - เดิมทุกแพ็กเกจจากเกจ (12.5 ครั้ง/วิ) + GPS + ดาวเทียม + DEMO (20 ครั้ง/วิ) สั่งวาดทั้งหน้าใหม่ทุกครั้ง → ตอนนี้รวมให้วาดไม่เกิน ~30 ครั้ง/วิ
  - แยกเลเยอร์ (RepaintBoundary): พื้นหลัง, โลโก้, แต่ละหน้า, เกจกลาง, ช่องค่าแต่ละช่อง → ค่าไหนเปลี่ยนวาดเฉพาะช่องนั้น
  - กรอบเรืองแสง (blur) ของช่องค่าแคชไว้ ไม่ต้องคำนวณเบลอใหม่ทุกครั้งที่ตัวเลขเปลี่ยน
  - พื้นหลังลดความสว่างไว้ในรูปแล้ว (ไม่ต้องวาดชั้นดำทับทั้งจอ), หน้าเปิดแอพเหลือ 2.2 วิ (เดิม 4 วิ)
- การทำงานเดิมไม่เปลี่ยน: BLE, GPS, DRAG LOG, AFR LOG, DTC, ส่งโลโก้ไปเกจ

แพ็กเกจยังเป็น `com.ftp.gauge` → ติดตั้งทับแอพ FTP-CONNECT เดิมได้เลย ค่าที่ตั้งไว้/LOG ไม่หาย

## Build APK บน GitHub (เหมือนเดิม)
1. อัปโหลดไฟล์ทั้งหมดขึ้น repo (รวมโฟลเดอร์ `.github`)
2. แท็บ **Actions** -> "Build Android APK" (รันเองเมื่อ push หรือกด Run workflow)
3. รอบที่เสร็จ -> **Artifacts** -> ดาวน์โหลด `TIWSHOP-apk`
4. ติดตั้งบนมือถือ Android (อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก)
